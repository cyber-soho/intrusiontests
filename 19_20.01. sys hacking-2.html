🎭 Network Interception Dynamics

Modern switched networks require active manipulation to intercept traffic, unlike legacy hubs where passive eavesdropping was sufficient. This section breaks down the transition from passive monitoring to active Man-in-the-Middle (MITM) attacks, focusing on the critical vulnerability within the 1982 ARP protocol that allows attackers to redirect LAN traffic seamlessly.

Passive vs. Active Sniffing

👂

Passive Sniffing

Works on legacy hubs and wireless networks. The NIC is set to promiscuous mode to read broadcast traffic silently. No packet injection is needed.

🗣️

Active Sniffing

Required on modern switched networks. Switches only forward frames to the correct port. Attackers must manipulate the network (MAC flooding, ARP spoofing, DNS spoofing) to force traffic their way.

MITM Defence Stack

  • ✓ TLS/HTTPS everywhere: Encrypt all traffic
  • ✓ HSTS: Prevent SSL stripping
  • ✓ Certificate pinning: Detect fake certificates
  • ✓ VPN tunnels: Encrypt at the network layer
  • ✓ DAI (Dynamic ARP Inspection): Validate ARP on switches
  • ✓ Network segmentation: Limit broadcast domains via VLANs
Key Takeaway: Encryption defeats content interception; network controls defeat positioning attacks.

The Anatomy of ARP Spoofing (T1557.002)

Exploiting RFC 826's lack of authentication

ARP maps Layer 3 IP addresses to Layer 2 MAC addresses. Because devices accept ARP replies without verifying identity or even sending a request, an attacker can manipulate local routing.

🔍 PCAP Forensic Analysis

Once traffic is intercepted, it is recorded in PCAP files. Raw network captures contain immense noise. Analysts rely on rigorous methodologies and specific display filters in tools like Wireshark to isolate credentials, reconstruct transferred files, and identify malware command-and-control beacons.

The 6-Step Workflow

  1. Big Picture: Statistics → Conversations.
  2. Identify Protocols: Protocol Hierarchy.
  3. Filter Sensitive Traffic: Apply display filters.
  4. Follow Streams: Reconstruct full TCP/HTTP sessions.
  5. Export Objects: Extract transferred files.
  6. Hunt Anomalies: Beacons, suspicious DNS.

"Structured PCAP analysis turns 80,000 raw packets into a concise report with 14 credential findings in minutes."

Essential Wireshark Filters

Filter Syntax Purpose
http All HTTP traffic
http.request.method == POST POST requests (credentials)
ftp.request.command == PASS FTP passwords
dns DNS queries/responses
ip.addr == 10.0.2.5 Traffic to/from specific host
tcp.flags.syn==1 && tcp.flags.ack==0 New connections (SYN)
arp.opcode == 2 ARP replies (spoofing detection)
frame contains "password" Frames with "password" string
tls.handshake.type == 1 TLS Client Hello
!arp && !dns && !icmp Remove common noise

🦠 Malware & Endpoint Defence (EDR)

Once network access is established, attackers deliver weaponized payloads (Malware). Because the traditional network perimeter has dissolved (due to Cloud, BYOD, Remote work), modern security focuses on controlling the endpoints themselves. Explore the categories of malware and how Endpoint Detection & Response (EDR) platforms shift the paradigm from static signature matching to behavioral analysis.

Malware Threat Landscape

Categorization of malicious payloads delivered via MITM, phishing, or exploits.

Vectors: Email, Drive-by, Trojanised Apps, USB.
Safety: Isolated VMs, Snapshots, Hash tracking.

The Evolution of Defence

From Legacy Antivirus to modern EDR/XDR

Traditional AV

Asks: "What does the file look like?" Relies on signature matching for known threats. Action: Block/Quarantine.

EDR (Endpoint Detection & Response)

Asks: "What does the file DO?" Relies on continuous behavioral monitoring across processes, network, memory. Action: Isolate, Investigate, Remediate.

XDR (Extended Detection & Response)

Integrates telemetry from endpoint, network, cloud, email, and identity into one platform.

⚖️ Legal & Ethical Reminders

  • Written authorisation required before any testing.
  • CFAA (U.S.) & Criminal Code of Canada, s.342.1 strictly forbid unauthorised computer use.
  • Sniffing/spoofing on unauthorised networks is a criminal offence.
  • Clean up after testing: restore ARP tables, remove artifacts.
  • Document everything: findings must be evidence-based.
  • The line between penetration tester and criminal is a signed piece of paper.
